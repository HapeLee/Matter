# Matter 无圆环凝核配色

沿用 A 的柔软轮廓、偏心透明开孔和三档明暗；移除外环，主体放大 1.45 倍并按轮廓居中。

- 雾蓝：#B9C9DD / #7E96B4 / #536B88
- 灰紫：#C5C2D9 / #9791B3 / #6C6689
- 青灰：#BDCEC9 / #88A69F / #5D7E77

每组包括透明底 SVG 与白底圆角展示稿。没有渐变或位图，浅底和深底预览使用同一配色。以上三组为配色探索。当前选用的应用图标是进一步提亮后的清新蓝版本。

## 当前应用图标

选用 `matter-fresh-blue.svg`：#B4D1EB / #82AFD6 / #567FA9，透明开孔、无圆环。`refine-blue.py` 生成设计稿；`export-android.py` 从该 SVG 导出实际 Android 前景与单色图层。白底由 adaptive icon 独立提供。

导出时按 108 dp 图层与 72 dp 名义裁切补偿比例，保持已确认设计稿中的主体占比。主题单色版本保留完整轮廓和透明孔。`matter-launcher-preview.svg` 为实际导出路径的静态裁切预览，非真机截图。
